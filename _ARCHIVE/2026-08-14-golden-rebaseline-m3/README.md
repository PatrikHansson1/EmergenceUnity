# Golden re-baseline triage — 2026-08-14, engine 2.5.1 -> 2.6.0 (M3)

The ore was on the map. The techs existed. The insights existed in GATHER_OBS. And the only code path
that sends a soul to a tile out of curiosity carried a hardcoded list of six materials that did not
include copper, tin, coal, gold or pigment. So nobody ever picked up the strange green stone, and
bronze -- with steel, the clock, the press and the steam engine behind it -- could not happen in any
world, at any seed, at any length of run.

These are the canonical outputs of the run that went RED against the 2.5.1 goldens. They ARE the new
goldens, kept here as the record of the moment the line moved.
